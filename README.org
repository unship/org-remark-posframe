#+TITLE: Org-remark-posframe

[[file:https://img.shields.io/badge/License-GPLv3-blue.svg]]

Org-remark-posframe previews the marginal note
([[https://github.com/nobiot/org-remark][Org-remark]]) for the highlight at
point in a child frame (posframe).

By default the posframe appears *just below* the highlight, so the highlighted
text stays visible while you read its note.

[[file:./demo-show-posframe.gif]]

(The GIF predates the rename from =org-marginalia= and the below-the-highlight
positioning.)

* Requirements
- Emacs 27.1+
- [[https://github.com/nobiot/org-remark][org-remark]] 1.0+
- [[https://github.com/tumashu/posframe][posframe]] 1.0+
- A graphical Emacs frame (posframe renders in a child frame)

* Setup
** Load
#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/org-remark-posframe")
(require 'org-remark-posframe)
#+end_src

** Notes location
Org-remark resolves the marginal-notes file through ~org-remark-notes-file-name~.
With the default string value, notes live in a per-directory =marginalia.org=:
#+begin_src emacs-lisp
(setq org-remark-notes-file-name "marginalia.org")
#+end_src
For one notes file per source (=FILE-notes.org=), use the function option:
#+begin_src emacs-lisp
(setq org-remark-notes-file-name #'org-remark-notes-file-name-function)
#+end_src
See the Org-remark manual for details.

** Keybindings
#+begin_src emacs-lisp
(with-eval-after-load 'org-remark
  (define-key org-remark-mode-map (kbd "C-M-}") #'org-remark-posframe-next)
  (define-key org-remark-mode-map (kbd "C-M-{") #'org-remark-posframe-prev))
#+end_src

** Dismiss with C-g (optional)
Enable the global minor mode so that ~C-g~ hides the preview posframe:
#+begin_src emacs-lisp
(org-remark-posframe-mode 1)
#+end_src

* Usage
- ~M-x org-remark-posframe-show~ — preview the note for the highlight at point.
- ~M-x org-remark-posframe-next~ — move to the next highlight and preview it.
- ~M-x org-remark-posframe-prev~ — move to the previous highlight and preview it.
- ~M-x org-remark-posframe-hide~ — hide the posframe (or ~C-g~ with the minor mode).

Click a link inside the posframe to jump to its target.

* Customization
~M-x customize-group RET org-remark-posframe~.
- ~org-remark-posframe-poshandler~ — where the posframe appears. Default
  ~posframe-poshandler-point-bottom-left-corner~ (below the highlight). Any
  [[https://github.com/tumashu/posframe][posframe]] handler works, e.g.
  ~posframe-poshandler-window-bottom-right-corner~ to pin it to a window corner.
- ~org-remark-posframe-background-color~ — background for a plain note.
- ~org-remark-posframe-todo-color~ / ~org-remark-posframe-done-color~ —
  background tint when the note's heading is a TODO / DONE entry.
- ~org-remark-posframe-internal-border-width~ — border width in pixels.
